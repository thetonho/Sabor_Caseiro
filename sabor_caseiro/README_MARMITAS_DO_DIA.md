# Marmitas do Dia — Supabase

Este projeto usa o Supabase para PostgreSQL, Auth, Storage e RLS.

## Banco que já existe
Execute apenas `ATUALIZACAO_CATALOGO_MARMITAS_DO_DIA.sql` uma vez no SQL Editor do Supabase.

## Projeto novo
`banco_supabase.sql` já inclui o catálogo de Marmitas do Dia no final do arquivo.

## Fluxo
No painel Administrador, abra **Marmitas do Dia**. É possível criar, editar, duplicar, excluir e publicar marmitas usando os tamanhos e ingredientes já cadastrados no Supabase. Apenas uma fica publicada por vez e ela aparece automaticamente na página inicial.
